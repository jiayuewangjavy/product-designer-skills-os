# Designer Core profile

This is a routing preset, not a required sequence.

## Install

- `product-design-router`
- `product-context`
- `opportunity-and-assumption-map`
- `conceptual-model-design`
- `prototype-question`
- `interactive-prototype`
- `design-judgment-scorecard`
- `intent-preservation-check`

## Default emphasis

Raise the priority of Meaning & Structure and Experience & Judgment risks. Add `position-and-launch-hypothesis` when adoption, positioning, or market evidence is consequential to the decision.
