# Full Collection profile

The v0 full collection contains every implemented capability node. Installing all skills does not mean running all skills for every task; `product-design-router` should still select the smallest useful loop.

## Install

- `product-design-router`
- `product-context`
- `opportunity-and-assumption-map`
- `conceptual-model-design`
- `prototype-question`
- `interactive-prototype`
- `design-judgment-scorecard`
- `intent-preservation-check`
- `position-and-launch-hypothesis`
- `learning-loop-readout`

## Still outside v0

Dedicated research synthesis, journey / flow, state-permission-recovery, usability evidence, design-to-code contract, instrumentation, accessibility, and retention modules remain candidates. Add them only after a v0 evaluation demonstrates a recurring gap that cannot be handled cleanly by the current nodes.
