# Builder Core profile

This is a routing preset, not a required sequence.

## Install

- `product-design-router`
- `product-context`
- `opportunity-and-assumption-map`
- `conceptual-model-design`
- `prototype-question`
- `interactive-prototype`
- `design-judgment-scorecard`
- `intent-preservation-check`
- `position-and-launch-hypothesis`
- `learning-loop-readout`

## Default emphasis

Raise the priority of Value, Feasibility, Adoption, and Learning risks. Do not treat build completion, traffic, or launch as validation without an explicit hypothesis and interpretable signal.
